## 7. UTM scheme

Every destination URL gets tagged so you can tell which platform actually converts:

```
https://coolerup.lovable.app/?utm_source=tiktok&utm_medium=paid&utm_campaign=launch_less_perfect&utm_content=hook_h2_no_filters
https://coolerup.lovable.app/?utm_source=meta&utm_medium=paid&utm_campaign=launch_less_perfect&utm_content=hook_h4_nobodys_perfect
https://coolerup.lovable.app/?utm_source=youtube&utm_medium=paid&utm_campaign=launch_less_perfect&utm_content=bumper_6s
```

Convention: `utm_content` = creative hook ID, so a winning hook is traceable to a winning ad.
